WATCH MART - LIVE SERVER EDITION

HOW TO RUN IN VS CODE LIVE SERVER
1. Extract this ZIP file.
2. Open the extracted folder in VS Code.
3. Install the VS Code extension named "Live Server" if it is not installed.
4. Right-click index.html and choose "Open with Live Server".
5. The site will open in your browser, usually at http://127.0.0.1:5500.

FEATURES
- 64 watch catalogue items including Apple Watch, smartwatches, kids watches, sports, digital, analog and classic watches.
- Search, category filters, product details, cart, Buy Now and checkout.
- Demo login, successful order screen and Placed Orders history.
- Orders and demo accounts are saved in this browser using localStorage.
- No npm install, Node.js server or database setup is needed for this Live Server edition.

IMPORTANT LIMITATIONS
- This is a frontend-only Live Server version. localStorage data stays in the same browser/device and is not stored in a central server database or shared between devices.
- Demo account passwords are stored in this browser and this is NOT secure authentication. Do not use real passwords or sensitive personal information.
- UPI is a demo selection only. No real payment is processed.
- Product images use model-specific image-search thumbnail URLs and require an internet connection. The first result may still be a similar variant, not guaranteed exact. Check the model number and official brand listing before purchase. For verified exact photography, replace each image URL with the official product image URL from the brand/manufacturer page.

If you need orders stored centrally in a database and shared across devices, use the separate backend version and start it with npm start instead of Live Server.


MODEL IMAGE NOTE
Each catalogue item has a distinct query based on its brand and model name instead of reusing the same stock photo. Image results are dynamic and are not guaranteed to be exact official product photography.
